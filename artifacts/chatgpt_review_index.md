## Instructions for ChatGPT (paste with the URL list)

1. Enable **web search**.
2. **Fetch and read** each linked markdown (prefer raw.githubusercontent.com if blob pages are awkward).
3. Reply with a **structured review for R1–R5** (one section per round), staying inside claim boundaries.
4. Do not invent metrics; treat live numbers in the paste packages as authoritative for this pilot.
5. Suggest manuscript wording only where it is claim-safe.

### Claim boundaries (do not drift)

- Open multi-source flood labels only — **no PFIb** / no proprietary insurance claims.
- Primary evaluation: **spatial H3-block GroupKFold CV** (not random split as primary).
- `PFI_h(c,r)` = rainfall-conditioned hex flood **probability/index** from the model — **not** feature importance and **not** 7Analytics PFIb / PFIh aggregation product.
- Lower Manhattan smoke ≠ citywide; Oslo / fixtures = appendix / QA only.
- Do **not** claim PFIb reproduction or Jaccard equality to Svellingen’s ≈0.14.
- Synthetic rainfall hook ≠ radar; flat within-cell scenario `PFI_h` must stay honest (待补充 if claiming event discrimination).
